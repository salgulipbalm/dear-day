# Dear, Day

빈티지 종이 다이어리 분위기의 질문·쪽지 사이트입니다.

## 포함된 기능
- 질문 / 비밀쪽지 보내기
- 익명 또는 닉네임 선택
- 쪽지별 확인 코드 발급
- 확인 코드로 답장 확인
- 관리자 로그인 및 전체 쪽지함
- 각 쪽지에 개별 답장
- 답장을 확인 코드 전용 또는 공개로 설정
- 질문 거절 및 다시 받기

## Netlify 배포 전 준비
1. 이 ZIP을 풀고 GitHub의 새 저장소에 파일을 올립니다.
2. Netlify에서 **Add new site → Import an existing project**로 새 저장소를 연결합니다.
3. Netlify 사이트 설정의 Environment variables에 `ADMIN_PASSWORD`를 추가합니다.
4. `ADMIN_PASSWORD`의 값은 추측하기 어려운 새 비밀번호로 정합니다. 다른 사람과 공유하지 마세요.
5. Deploy를 실행합니다. Netlify Functions와 Netlify Blobs는 Netlify 배포 환경에서 동작합니다.

## 중요
- `ADMIN_PASSWORD`는 브라우저 코드에 넣지 마세요. 서버 함수가 환경 변수에서 읽습니다.
- 로컬 파일을 더블클릭해서 열면 서버 기능은 작동하지 않습니다. Netlify에 배포한 뒤 테스트하세요.
- 질문 내용은 최대 500자이며, 주소·전화번호·학교 등 개인정보를 적지 말라는 안내가 표시됩니다.
- 공개 답변은 사이트 방문자가 볼 수 있는 공개 기록 기능의 기초로 저장됩니다. 현재 첫 버전에서는 개별 답장 확인 화면에서 공개 답변도 확인 코드로 확인합니다.
- 이 프로젝트는 첫 번째 작동 버전입니다. 실제 친구들에게 공유하기 전, 관리자 비밀번호 설정과 테스트를 먼저 마쳐 주세요.
